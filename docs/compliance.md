# OVIC & VPDSF Compliance Model

## OVIC Principles Applied
- IPP 1–3: Collection minimisation
- IPP 4: Data security
- IPP 8–9: Anonymity and restricted use

## VPDSF Alignment
Security domains enforced:
- Information Security
- Access Control
- Data Minimisation
- Auditability (without data retention)

## Enforcement Rules
When OVIC/VPDSF mode is enabled:
- All identifiers must be abstracted
- No personal, health, or sensitive data may persist
- No memory or history is retained
- Prompts must instruct AI systems to avoid inference

## Default State
OVIC/VPDSF mode is **ON by default**.

Opt-out must be explicit and local-only.
