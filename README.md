# PromptForge

PromptForge is a **local-first, OVIC/VPDSF-compliant prompt generator**
designed to maximise output quality across GenAI platforms
without exposing regulated data.

## What This Is
- A prompt compiler
- A compliance enforcement engine
- A platform-aware instruction generator

## What This Is NOT
- Not a chatbot
- Not an AI wrapper
- Not a SaaS product
- Not cloud-dependent

## Compliance Focus (Phase 1)
- OVIC (Victorian Information Privacy)
- VPDSF (Victorian Protective Data Security Framework)

All data is assumed to be:
- De-identified
- Synthetic
- Non-persistent

## Supported Platforms (Initial)
- Claude
- Claude Code

## Operation Model
- Runs fully locally
- No data storage by default
- Clipboard output only

See `/docs/compliance.md` for details.
